# 部署到自己的服务器（Docker）

一台 x86_64 Linux 小机器 + Docker 就够，镜像很小（约 60MB），不装数据库、不联网。

> **已部署实况（mini，2026-11-09）**
> - 主机：`192.168.11.37`（Debian 13 / x86_64 / 4 核 31G），Docker 29.9 + Compose v5.7
> - 编排：`/mnt/data/compose/pdf-board/compose.yaml`（Dockge 里可见，栈名 `pdf-board`）
> - 镜像：`pdf-board:local`（约 255MB，含 node:22-alpine 基础层）
> - 数据：`/mnt/data/pdf-board/boards/`（挂进容器 `/data`）
> - 访问：<http://192.168.11.37:7420/>
> - 已登记到 Homepage 面板「应用」组（配置备份：`/mnt/data/homepage/config/services.yaml.bak-20261109221744`）
> - 常用操作：`cd /mnt/data/compose/pdf-board && docker compose up -d --build`（更新） / `docker compose logs -f` / `docker compose down`

## 1. 把文件传上去

在服务器上建个目录，把整个 `pdf-board` 目录（含 `Dockerfile`、`docker-compose.yml`、`vendor/`）传进去：

```bash
# 在你自己的电脑上执行
scp -r pdf-board me@my-server:/opt/
```

## 2. 起服务

```bash
cd /opt/pdf-board
docker compose up -d --build
```

浏览器打开 `http://<服务器IP>:7420/` 即可。

第一次打开会自动建一块「白板 1」，顶栏出现「白板 ▾ ＋ ✎ 🗑」：

- 下拉框切换 / 新增 / 重命名 / 删除白板
- 每块板都在服务器上，**换电脑、换浏览器打开都是同一套内容**
- 改完约 0.7 秒自动保存，右上角显示「保存中… / 已保存」

## 3. 数据在哪

```
./data/boards/<id>.json        每块白板的完整内容
./data/boards/<id>.meta.json   列表用的轻量信息
```

备份：`tar czf backup-$(date +%F).tgz -C . data`
迁移：把整个 `data/` 拷到新机器同一位置即可。

## 4. 常用维护

```bash
docker compose logs -f          # 看日志
docker compose restart          # 重启
docker compose down             # 停止（数据在 ./data，不会丢）
docker compose up -d --build    # 更新代码后重新构建
```

## 5. 加访问口令（放到局域网之外时强烈建议）

`docker-compose.yml` 里取消这行注释并改成自己的口令：

```yaml
PDFBOARD_TOKEN: "my-secret"
```

然后：

```bash
docker compose up -d
```

之后要访问 `http://<服务器IP>:7420/?token=my-secret`，页面会把口令记在本机浏览器里，下次直接开就行。

## 6. HTTPS（可选）

剪贴板 API（把框选图直接写进系统剪贴板、粘贴到 Word/微信）需要**安全上下文**：
`http://localhost` 可以，但局域网 `http://IP` 不行——主流程「框选 → 贴到白板」不受影响。

要保住剪贴板功能，用 Caddy 反代 + 自签/域名证书即可，`Caddyfile`：

```
pdf.example.com {
    reverse_proxy 127.0.0.1:7420
}
```

放在子路径（`https://host/pdfboard/`）也支持，用 `handle_path /pdfboard/*` 即可（前端 API 路径会自动跟随）。

## 7. 这个方案不做什么

- **不在服务器上存 PDF**：PDF 还是你在浏览器里选本地文件打开（浏览器安全限制），服务器只看得到白板内容。
- **服务端不做图片压缩**：贴进去的是原始高清截图，一块板可以到几十 MB（上限由 `PDFBOARD_MAX_MB` 控制）。
- **没做用户系统**：默认所有拿到地址的人共用一批白板；多人一起用请开 `PDFBOARD_TOKEN`。

## 8. 不用 Docker 也可以

有 Node.js 18+ 的机器上直接跑（systemd 示例）：

```ini
[Unit]
Description=PDF Board
After=network.target

[Service]
WorkingDirectory=/opt/pdf-board
Environment=PDFBOARD_HOST=0.0.0.0
Environment=PDFBOARD_DATA=/opt/pdf-board/data
Environment=PDFBOARD_NO_OPEN=1
ExecStart=/usr/bin/node server.mjs
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```
