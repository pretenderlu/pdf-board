# PDF 摘录白板 · 规格与接口契约 v1

本地离线单页应用：左侧 PDF 阅读器（框选区域）→ 右侧无限白板（粘贴、摆布、批注）。
用户场景：把试卷/资料里的题目一块块框出来，贴到白板里整理。

## 1. 模块划分与职责

| 路径 | 职责 | 说明 |
|---|---|---|
| `index.html` | 外壳 | 顶栏、两栏挂载点、分割条、toast、帮助弹窗 |
| `css/app.css` | 外壳样式 | 设计令牌 + 顶栏/分栏/toast 外壳样式 |
| `js/app.js` | 装配层 | 实例化两个模块、文件打开、剪贴板桥、保存/导出 |
| `server.mjs` `启动.cmd` | 启动 | 本地静态服务器 + 双击启动 |
| `js/pdf-pane.js` | PDF 阅读器 | 自建内部 DOM，类名前缀 `.pdfp-` |
| `css/pdf-pane.css` | PDF 样式 | 类名前缀 `.pdfp-` |
| `js/board.js` | 白板引擎 | 自建内部 DOM，类名前缀 `.bp-` |
| `css/board.css` | 白板样式 | 类名前缀 `.bp-` |
| `vendor/pdfjs/**` | 依赖 | pdf.js 4.10.38（pdf.mjs / pdf.worker.mjs / cmaps / standard_fonts） |

模块之间只通过 `js/app.js` 传入的回调与构造参数通信，不互相直接引用；`vendor/` 不要改动，也不新增 npm 依赖（离线环境，pdf.js 已内置）。

## 2. 运行环境事实

- 页面通过本地 http://127.0.0.1 访问（`node server.mjs`），因此 `navigator.clipboard`、ES module、Web Worker 均可用。
- pdf.js 用 ESM：`import * as pdfjsLib from '../vendor/pdfjs/build/pdf.mjs'`（`js/` 下的相对路径）。
- worker 路径：`../vendor/pdfjs/build/pdf.worker.mjs`，必须设置 `pdfjsLib.GlobalWorkerOptions.workerSrc`。
- 中文 PDF 必须设置 `cMapUrl: '../vendor/pdfjs/cmaps/'`、`cMapPacked: true`、`standardFontDataUrl: '../vendor/pdfjs/standard_fonts/'`（getDocument 参数）。
- 目标浏览器：Chromium/Edge 最新版（Windows 11）。不要用实验性 API。
- 全部代码为纯 ES module，无构建步骤；不要用 TypeScript / JSX / npm import。

## 3. 设计令牌与外壳（由 css/app.css 提供，可直接使用）

```css
:root{
  --bg:#eef0f4; --panel:#ffffff; --panel-2:#f7f8fa; --line:#dfe3e9; --line-strong:#c6ccd6;
  --text:#1f2329; --muted:#6b7280; --accent:#2f6df6; --accent-weak:#e8effd; --accent-press:#1f57d0;
  --danger:#e5484d; --ok:#18a058; --shadow:0 6px 24px rgba(20,26,38,.14);
  --radius:10px; --radius-sm:6px; --topbar-h:48px;
}
```
布局：`#split` 是 flex 行，`#pdfPane`/`#boardPane` 各占一份（宽度由外壳层的拖拽分割条控制），两个 pane 都是 `display:flex; flex-direction:column; overflow:hidden`。
**模块根元素必须 `height:100%; width:100%; overflow:hidden`，自建内部滚动区，不要依赖外部滚动。**

可用外壳辅助：
- 按钮基础类：`.btn`（含 `.btn.primary`、`.btn.ghost`、`.btn.icon`），尺寸 30px 高。
- `window.toast(msg)`：右下角提示（外壳层提供，全局可用；可能尚未就绪，调用请写 `window.toast?.(msg)`）。
- 图标一律用内联 SVG（`<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.8">`），不要外链字体/图片。

## 4. 共享数据结构

### 4.1 剪贴块 ClipPayload（PDF → 白板）

```ts
type ClipPayload = {
  type: 'clip',
  page: number,        // 1 基页码
  dataUrl: string,     // 'data:image/png;base64,...' 裁切图
  width: number,       // 图片像素宽
  height: number,      // 图片像素高
  text: string,        // 框内提取到的文字（可能为 ''，扫描件为空）
  dpr: number          // 裁切图相对 PDF 1x 视图的倍率，用于还原板上显示尺寸
                          // 建议：onBoardWidth = width / dpr（CSS px）
}
```

### 4.2 白板元素 item

```ts
type Item =
 | { id, type:'image', x, y, w, h, z, src, page?, naturalW, naturalH }
 | { id, type:'text',  x, y, w, h, z, text, fontSize, color }
 | { id, type:'stroke', z, points:[{x,y},...], color, width, opacity, tool:'pen'|'highlighter', bbox:{x,y,w,h} }
```
坐标一律为**世界坐标**（1 单位 = 100% 缩放下的 1 CSS px）。持久化格式：
```json
{ "version": 1, "view": { "x": 0, "y": 0, "scale": 1 }, "items": [ ... ] }
```

## 5. js/pdf-pane.js 契约

```js
export class PdfPane {
  constructor(host, { onSendToBoard, onClipAvailable, toast }) {}
  async open(file)              // File | ArrayBuffer；失败返回 false 并 toast
  get loaded()                  // boolean
  get pageCount()
  goToPage(n, { smooth=false })
  nextPage() / prevPage()
  zoomIn() / zoomOut() / fitWidth() / setZoom(z)
  get currentPage()
  destroy()
}
```
行为要求：
1. 顶部工具条（模块自建）：打开文件按钮不需要（外壳有），需要：上一页/下一页、页码 `n / N`（可输入跳转）、缩放 `−`/`+`/`适应宽度`。
2. 连续滚动查看全部页，按需渲染（IntersectionObserver 或 scroll 计算），页面白底+投影，页与页有间距；默认适应宽度。
3. **框选**：在页面上按下拖拽 → 显示虚线选框；支持框边缘 8 个手柄微调；选区外按 Esc/点击空白取消。
4. 选区浮条（跟随选区，靠近选区内上沿，超出边界时翻到下方），按钮：`→ 贴到白板`（主操作）、`贴文本`、`复制`、`×`。
5. 生成 ClipPayload：用 pdf.js 把该页离屏渲染成位图（缩放 = `max(2, 当前视图缩放*1.5)`，且总宽度上限 4000px），再按选区裁切，输出 PNG dataURL；`dpr` = 该渲染缩放 / 当前视图缩放……简化：直接令 `dpr = 离屏渲染缩放 / 当前视图缩放`，保证贴到板上后尺寸与屏幕所见一致。
6. 文字提取：用 `page.getTextContent()`，把落在选区内的文本项按行拼接（保留换行）。扫描件返回 `''`（此时"贴文本"按钮置灰并提示"本页无文本层（扫描件）"）。
7. 选区完成时：调用 `onClipAvailable(payload)`（外壳缓存为内部剪贴板），并**尽力**把 PNG 写入系统剪贴板（`navigator.clipboard.write([new ClipboardItem({'image/png': blob})])`，失败静默忽略）。
8. 键盘（在 pane 内有效）：`Ctrl/Cmd+C` 复制当前选区图；`←/→` 上/下一页；`+/-` 缩放；`Esc` 清除选区。
9. 无文件时显示空状态：提示"打开 PDF 或把文件拖到这里"（文件拖放由外壳层处理，模块只负责显示）。
10. 模块不得修改外壳层文件（`index.html` / `js/app.js` / `css/app.css`）。

## 6. js/board.js 契约

```js
export class Board {
  constructor(host, { getFallbackClip, toast }) {}
  addClip(clip, { center = true })   // 生成 image item，自动选中；center=放在当前视口中央（不重叠：每次略微错位）
  addText(text, { x, y, fontSize })
  clear()
  undo() / redo()
  exportPNG()                        // 导出全部内容为 PNG 并触发下载
  toJSON()                           // 返回可持久化对象
  loadJSON(obj)                      // 恢复（容错：坏数据不崩）
  fitContent()                       // 缩放到能看到全部内容
  get hasContent()
  destroy()
  get view()                         // {x,y,scale}
}
```
行为要求（全部必须实现并自测）：
1. **无限画布**：点阵网格背景（随缩放/平移变化，缩得太小则淡出）；平移/缩放平滑。世界坐标变换 `screen = (world * scale) + translate`。
2. **平移**：空格+左键拖、中键拖、右键拖、触控板双指；`Shift+滚轮` 水平、普通滚轮垂直、`Ctrl+滚轮` 以光标为中心缩放（0.1x–8x）。
3. **工具条**（模块自建，悬浮在顶部）：选择 / 画笔 / 荧光笔 / 橡皮 / 文字；缩放 `−` `%` `+`、`适应内容`、`清空`（二次确认）。
4. **元素操作**：点选、Shift 多选、空白拖拽框选（marquee）、拖动移动（多选整组移动）、四角手柄缩放（图片 Shift 锁定比例）、`Delete/Backspace` 删除、方向键微调（Shift=10px）、`Ctrl+A` 全选、`Ctrl+D` 复制、`Ctrl+]/Ctrl+[` 置顶/置底、`Ctrl+Z`/`Ctrl+Shift+Z` 撤销重做。
5. **粘贴**：`Ctrl/Cmd+V` → 优先系统剪贴板图片（`navigator.clipboard.read()`），失败则用 `getFallbackClip()`（PDF 内部剪贴板）；也支持 `drag & drop` 图片文件到板上。粘贴后自动选中，落在视口中央。
6. **图片元素**：显示 `P{page}` 小角标；圆角+细边框+柔和阴影；缩放到世界坐标下按 `w,h` 渲染，保持清晰。
7. **文字元素**：双击空白处新建文字并进入编辑；双击文字元素进入编辑（contenteditable），失焦/Enter 提交，Esc 取消；空文本自动删除。文字使用系统字体，可设为 `--text` 色。
8. **画笔**：自由画线，world 坐标记录，二次曲线平滑；荧光笔半透明黄色/青色、圆头粗线；橡皮擦点击或拖动擦除整笔。
9. **选中态 UI**：元素外框 1.5px 蓝线 + 四角方块手柄 + 浮动小工具条 `置顶/置底/删除`。
10. **自动保存**：变更后 500ms 防抖写入 `localStorage['pdfboard.v1']`，启动时自动恢复；顶部工具条显示"已保存"淡文字。
11. **导出 PNG**：把全部内容（含网格可选、留白 40px、白色背景）渲染到离屏 canvas（2x 分辨率），`a[download]` 保存为 `白板-YYYYMMDD-HHmm.png`。
12. 空板提示：居中文案"框选左侧 PDF 区域 → 点「贴到白板」或 Ctrl+V"。

## 7. 交互总流程（验收口径）

1. 打开 PDF → 左栏显示页面。
2. 在页面上拖框 → 出现虚线选区 + 浮条。
3. 点「→ 贴到白板」→ 右侧出现该区域截图，自动选中，可直接拖动/缩放。
4. 或框选后按 `Ctrl+C`，到右栏按 `Ctrl+V` → 同样得到贴图。
5. 画笔画批注、双击加文字、框选多选、撤销、保存/导出全部可用。
6. 刷新页面白板内容仍在（有后端时来自服务器；纯静态托管时来自 IndexedDB）。
7. 全流程无 console 报错。

## 8. 存储与后端 API（v2 新增）

白板默认由 `server.mjs` 存成文件（`PDFBOARD_DATA`，默认 `./data`），浏览器不再是唯一数据源；
页面启动时用 `GET api/health` 判断有没有后端：**有** → 服务器模式（Board 用 `persistence:'off'`，由外壳驱动保存）；
**没有**（纯静态托管） → 本机模式（Board 用自己的 IndexedDB，行为同 v1）。

### 8.1 Board 的外部持久化接口（js/board.js）

```js
new Board(host, {
  persistence: 'auto' | 'off',   // off = 完全不碰 IDB/localStorage
  onChange(doc),                 // 内容或视图变化后触发（500ms 防抖），loadJSON/恢复不触发
  setSavedState(text, state),    // 可选：把状态文字交给外壳
});
board.loadJSON(data, { silent: true });  // 默认静默：不触发 onChange、不写存储；会重置撤销栈与选中
board.markClean();                       // 清掉 pending 保存，标记为干净基准
```

### 8.2 HTTP 接口（全部支持 `/api/...` 或反向代理子路径下的 `.../api/...`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | `{ok,server,boards,tokenRequired,maxMB}`；无后端时返回 404，前端据此回退本机模式 |
| GET | `/api/boards` | 列表（读 meta，不读正文）：`{boards:[{id,name,createdAt,updatedAt,rev,itemCount,bytes}]}` |
| POST | `/api/boards` | 新建 `{name?, data?}` → 201 `{board}` |
| GET | `/api/boards/:id` | 取完整白板 `{id,name,rev,data}` |
| PUT / POST | `/api/boards/:id` | 保存整块 `{rev?, data}`；`rev` 不匹配 → 409 `{rev}`（POST 别名是给 `sendBeacon` 用的） |
| PATCH | `/api/boards/:id` | 重命名 `{name}`（亦可 `POST .../rename`） |
| DELETE | `/api/boards/:id` | 删除 |

- 访问口令：设置 `PDFBOARD_TOKEN` 后所有 `/api/*` 需 `x-board-token` 请求头或 `?token=`；前端从 `?token=` 读取后存 localStorage 并自动带上。
- 落盘：`data/boards/<id>.json`（正文）+ `<id>.meta.json`（列表元信息）；启动时按文件重建索引，写入用 `.tmp` + rename。
- 关页兜底：`pagehide` 时若内容签名与最后一次落盘不同，用 `sendBeacon` POST 一次（只发 POST、体积受浏览器限制，属于最后一道保险）。

## 9. 自测建议

浏览器侧：用 Playwright 起 Chromium 打 `http://127.0.0.1:PORT`；起服务时用
`PORT=xxxx PDFBOARD_DATA=/tmp/xxx node server.mjs --no-open`，避免污染真实数据目录。
纯逻辑（坐标换算、命中测试、折行、数据清洗）可以不依赖浏览器，用 Node 加一个最小 DOM 垫片直接跑。
